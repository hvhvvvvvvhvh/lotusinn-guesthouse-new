LOTUS INN ADMIN LOGIN
=====================

Admin URL:
  /admin/login

Development-only fallback password:
  LotusInn@2026!

IMPORTANT FOR LIVE DEPLOYMENT:
Set these environment variables on the hosting platform:
  ADMIN_PASSWORD=your-strong-password
  ADMIN_SESSION_SECRET=your-long-random-secret

Production sign-in is disabled until both variables are configured.
Admin sessions use signed, expiring tokens in an HttpOnly cookie. Middleware,
server-rendered admin pages and admin API handlers each check authentication.

For persistent hosting, configure LOTUS_STORAGE_DRIVER=supabase and follow
SUPABASE-SETUP.md to install the schema, import content and set server secrets.
The json storage mode is retained for single-process local development.
